# Decision Variables and Objective Function - Acceptance Criteria

## Requirements
- Binary source activation variables (y_i) created for each water source
- Continuous source withdrawal variables (x_i) created for each water source
- Variable names correspond to mathematical notation
- Fixed source activation cost implemented
- Variable source withdrawal cost implemented
- Treatment cost for single treatment plant implemented
- Cost components separately identifiable
- Complete model objective is cost minimization

## Testing
- Unit tests created and passing
- Example file demonstrates usage
- Code runs without errors

## Documentation
- Code is well-commented
- Docstrings explain each method
