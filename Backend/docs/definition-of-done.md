# Definition of Done

## Sprint 1 Definition

Sprint 1 is complete when:

- The ASP.NET Core API, test project, documentation folders, and CI workflow are correctly scaffolded.
- The application restores, builds, and runs successfully.
- `GET /api/health` remains operational and returns a successful response.
- Controller support is enabled, and implemented controllers appear in OpenAPI.
- Entity Framework Core connects successfully to PostgreSQL.
- The initial migration and development seed data work correctly.
- Water Source and Scenario GET endpoints return the expected data and HTTP status codes.
- The proposed authentication, authorisation, and automatic-update approaches are implemented as proof of concepts or clearly documented.
- Automated tests pass using `dotnet test`.
- GitHub Actions successfully restores, builds, and tests the backend solution.
- No passwords, connection strings, API keys, or generated build files are committed.
- Completed work is reviewed and merged into `backend/sprint-1` through pull requests.
- Relevant Sprint 1 documentation is complete and up to date.
